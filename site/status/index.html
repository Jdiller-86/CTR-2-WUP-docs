    CTR2WUP status¶

    Updated October 13, 2026 (America/New_York) · v0.22.0. The target remains an UWUVCI-style Windows GUI: select an owned 3DS game, configure title/artwork, click Inject, install its individual WUP and play from Wii U Menu. Requirements, product plan, documentation and acceptance gates define scope.

    Approximately 20% implemented; 0/7 full milestones accepted. This is a rough engineering estimate, not a test-count percentage or release-date prediction. No commercial profile, playable Mario build, general PICA renderer or finished GUI is enabled. Current binaries are original homebrew diagnostics.

    v0.22.0 increment¶

    The first original scenes now execute PICA-format loader/index state, fixed attributes, packed/float32 uniforms and actual MOV/NOP/END shader instructions through a checked software triangle renderer. Byte and short index formats produce the same two-triangle square, with exact independent pixel comparison and whole-list rollback on late failure. A separate pinned nihstro comparison checks 12,290 shader/descriptor encodings, without copying or linking an emulator into the runtime.

    The original shader/scene suite passes 1,393,972 assertions. Required tests now include 372 Python tests and 21 normal/ASan/UBSan C suites; the report guide has 624 assertions. Native and focused Scene Check RPX/WUHB cross-builds pass. Receipts and actual desktop PNG output are retained in artifacts/reports/first-scenes-v022/; CI also publishes a focused wiiu-scene-check-<source commit> artifact with provenance and notices.

    See the scene contract and console guide. The focused check runs CPU rasterization and existing GX2 surface copies; physical picture, timing and exit evidence remains pending. Standard guest GSP still rejects draws. Arithmetic, textures/TEV, depth/blend, clipping, GPU shader translation and commercial profiles remain unsupported. This is a significant M4 foundation, not full M4 acceptance. The Audio Check/GX Transfers 0.20.0 launch-music regression remains open. Completed PR branches are deleted after merge.

    v0.21.0 increment (historical)¶

    The original vertex decoder now gathers resolved array attributes through unsigned 8-bit or little-endian unsigned 16-bit index buffers. It preserves duplicates and index order, handles unaligned buffers and explicit byte offsets, and checks every referenced range/value before changing any output. Unreferenced nonfinite vertex data does not reject a valid gather; 0xff/0xffff remain ordinary indices. Index buffers and descriptors receive the existing full-span alias protection. No heap allocation, PICA register interpretation, primitive assembly, shader execution or draw submission is introduced.

    The focused vertex suite passes 364,123 original assertions, including every 8-bit/16-bit index, reordered multi-stream/interleaved records, late rejection, aliasing, truncation and overflow. Required full-source and native-build receipts are retained in artifacts/reports/indexed-vertex-v021/. This advances M4's vertex/shader task without accepting the task or any full milestone.

    The focused Audio Check/GX Transfers 0.20.0 console handoff remains current; this independent vertex increment requires no repeated completed console guide. GitHub management continues through its verified Actions credential. Completed PR branches are deleted after merge.

    v0.20.0 increment (historical)¶

    All diagnostic variants initialize a fresh native AX context before running self-tests or waiting for input. An inherited same-process context is reset; owned voices are released before AX shutdown and foreground changes. Compiled apps acquire no tone voice. Failure states and lifecycle counters enter the small result and full trace. A two-step Audio Check asks whether launch music stopped and whether the original native tone played on both outputs. This is not 3DS guest audio, and physical silence remains pending.

    The private physical round now verifies named TXT read-back, original fresh-launch save reload, embedded/SD RomFS and GX transfer/configuration. Correct pictures and Minus return have user confirmation; the launch-music defect remains separate. The save completion prompt now explicitly distinguishes a fresh app launch from an in-app Plus restart.

    Project #2 population/overview/fields/views are verified using the Actions secret. Source tracking still cannot overwrite existing board values. Docs-only Pages publication and the dynamic chart are live through a reviewed trusted-main workflow. The site, dashboard, JSON and SVG return HTTP 200. Application source remains private.

    Validation: 371 Python tests and 20 normal/ASan/UBSan C suites pass; report/guide has 603 assertions and AX lifecycle has 149. Current Audio Check and compiled GX RPX/WUHB cross-builds passed. The pinned PICA matrix passes 353 original cases. Strict docs/link and public export/privacy checks pass; hosting/chart receipts are retained with this increment. Full milestone acceptance remains 0/7.

    v0.19.0 increment (historical)¶

    An original bounded vertex-attribute decoder handles signed8, unsigned8, signed16 and finite little-endian float32 from explicit streams/input permutations. It checks complete layouts, ranges, capacity and aliases before publishing output. Lane defaults are explicit; fixed/index attributes, PICA loader-state adaptation, float24 arithmetic, shaders and draws remain unsupported. See the vertex contract. GCC and Clang normal/ASan/UBSan and emulated big-endian PowerPC Linux pass 166,547 original assertions each. The devkitPPC module compiles; its measured decoder stack frame is 64 bytes. This is not physical Espresso execution or a rendered scene.

    Project #2 now owns tracking policy. Prepared tooling adds a preserved detailed Project overview, priority/work-type fields and filtered views, reads canonical board values, mirrors issue status/resources and exports safe aggregates for an interactive dashboard. Source sync carries requirements/evidence only, never existing tracking state. The README's static progress image is removed. Live population and hosted publication remain blocked: the secure personal requirement is saved, but the environment reports no saved binding and Project reads remain forbidden. No Project, website or token-enabled Actions run is falsely marked live.

    The focused console handoff is in artifacts/delivery/console-focus-2026-10-12/. Its hash-verified ZIP combines GX/PICA setup 0.18.0, retained Save/RomFS result fixes 0.14.6 and optional SD assets 0.16.0; every app version is explicit. Existing reports/snapshot siblings are preserved. The tester is now at their Wii U; new console evidence remains pending until reviewed. No long native/input rerun is required solely for the version increment.

    Reports: artifacts/reports/project-vertex-v019/ and the earlier vertex host receipt.

    v0.18.0 increment¶

    The bounded native PICA command front end now executes finalized raw viewport/ scissor configuration through standard GX command 1. Masks, repeated/grouped writes, full-stream/counter validation, staged guest input and P3D completion are implemented. Unknown registers, draws, uploads and control flags fail before state/output changes, retaining pending queue work. See the contract.

    Validation passes 306 Python tests and 18 C suites, normal and ASan/UBSan; the new PICA suite has 67,706 assertions and the integrated GX suite has 1,619. The independent pinned-libctru builder/C/Python matrix passes 353 original cases, with identical emulated big-endian PowerPC receipts. The compiled GX application executes 17 commands including one no-draw PICA list, exits after 1,489,172 instructions with zero fallback and retains exact prior transfer pictures. Native and compiled GX v0.18.0 RPX/WUHB cross-builds pass. Physical console behavior, actual draws/shaders and full M4 acceptance remain open.

    The owner supplied Project #2. The tracking tool selects it directly and cannot create a duplicate on access failure. Direct Project reads still return Resource not accessible by integration; its fields/items and automated population remain unverified. Normal repository Git/issue/CI work continues.

    Reports: artifacts/reports/pica-v018/. Earlier diagnostic kits remain preserved.

    v0.17.0 increment¶

    The standard GSP command ring now executes DMA, triggered memory fills, unscaled equal-size display conversion, raw strided texture copy and cache-region checks. It commits commands in order and preserves a failing entry/later work; all ranges/permissions/allocations are checked before that command changes output. Staging handles guest overlap, relay aliases are protected, and bulk memory writes invalidate exclusive/code snapshots including executable storage aliases. PSC/PPF/DMA completions follow bounded ring behavior. PICA lists remain unsupported.

    The original stock-libctru application uses 16 GX operations and verifies exact green/red/green TV images with blue GamePad pixels. Its sanitized AOT run exits after 1,487,784 instructions, zero fallback, with three deliberately unavailable startup services still recorded. Desktop PASS does not imply all services or Wii U rendering are implemented. The GX contract records alignment/size/format/layout limits and the optional two-step console guide.

    Independent review found and corrected missing fill-trigger validation and signaling for dropped interrupts. Required make check passes 291 Python tests and 17 C suites, normal and ASan/UBSan. GX has 1,102 assertions; report/guide has 587. The transfer matrix has 400 original C/Python/reference color/layout comparisons and matching emulated big-endian PowerPC hashes. Reference color/ Morton primitives were tested; the external full transfer engine was not. Fresh Native and GX Transfers RPX/WUHB cross-builds carry v0.17.0.

    Reports: artifacts/reports/gx-transfers-v017/. Delivery: artifacts/delivery/gx-github-0.17.0/, containing source/wheel, original Native/GX diagnostics, reference images, guides and checksum/manifest. The release record and CI provide repository-visible delivery/evidence; consult the actual Actions run status.
